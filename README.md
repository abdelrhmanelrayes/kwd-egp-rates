# تطبيق مقارنة سعر تحويل الدينار الكويتي للجنيه المصري (تحديث تلقائي بمتصفح حقيقي)

يعمل هذا المشروع مجاناً بالكامل عبر **GitHub Actions + Playwright + GitHub Pages**:
- يشغّل متصفح Chrome حقيقي كل **30 دقيقة** على سيرفرات GitHub.
- يسحب أسعار التحويل من مواقع البنوك الكويتية (التجاري، بيتك، برقان، الخليج، بوبيان، الوطني) والملا للصرافة (بعمولة 1.5 د.ك).
- يحدّث ملف `docs/rates.json` تلقائياً ويعرض الصفحة على رابط ثابت يشتغل على أي جهاز بدون حساب جيمناي.

## خطوات التشغيل (3 دقائق)
1. أنشئ مستودعاً جديداً (Public Repository) على [GitHub](https://github.com/new) باسم مثلاً `kwd-egp-rates`.
2. فك ضغط الملف وارفع جميع الملفات والمجلدات (بما فيها مجلد `.github` و`scripts` و`docs` و`package.json`) داخل المستودع.
3. من تبويب **Settings** ← **Pages**: اختر **Source: Deploy from a branch** ثم **Branch: `main`** والمجلد **`/docs`** واضغط **Save**.
4. من تبويب **Actions**: اختر **Update KWD to EGP Bank Rates** واضغط **Run workflow** لتشغيل أول تحديث فوراً (وبعدها سيتحدث تلقائياً كل 30 دقيقة).
5. افتح رابط موقعك من صفحة **Pages** (`https://<username>.github.io/kwd-egp-rates/`) وأضفه للشاشة الرئيسية على موبايلك!
